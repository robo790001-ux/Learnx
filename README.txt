# LearnX website

## Open locally
1. Extract the ZIP file.
2. Open `index.html` in a modern browser (Chrome, Edge, Firefox or Safari).
3. Choose **Get started** to create a demo student account.

## Included
- Responsive landing page for desktop and mobile
- Demo sign-up and login
- Student dashboard
- Course catalogue and sample lesson flow
- Sample quiz with feedback and XP
- Personal notes
- Progress and levels

## Important prototype limitations
This is a front-end prototype. Demo accounts, passwords, notes and progress are stored in the browser's localStorage. This is not secure authentication and does not sync between devices. Do not enter a real or reused password. A production release needs a backend, secure password hashing, database, email verification, authorization, and deployment/hosting.
